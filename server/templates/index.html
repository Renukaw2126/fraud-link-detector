About The Project

SafeLinker 🛡️

SafeLinker is a Machine Learning powered web application designed to detect phishing and fraudulent URLs in real time. Built using Python, Flask and XGBoost, it analyzes 87 URL-based features to predict whether a link is safe or malicious.

This project was built to raise awareness about online phishing attacks and provide a simple tool for everyday users to verify suspicious links before clicking them.
